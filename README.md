## 2026 Tournament Rules - Quick Guide

### Game Format

| Phase | Periods | Overtime |
|-------|---------|----------|
| Pool (Round Robin) | 12-12-15 min (stop time) | Tie stands |
| Elimination (1/8, QF) | 12-12-15 min (stop time) | 5 min 3v3, then shootout |
| Semi-Finals & Finals | 12-12-15 min (stop time) | 10 min 3v3, then shootout |

### Points System

| Result | Points |
|--------|--------|
| Win | 2 pts |
| Tie | 1 pt |
| Loss | 0 pts |
| Franc Jeu (Fair Play) | 1 pt |

### Key Rules

- **Mercy Rule**: If a team leads by 7+ goals after the 2nd period, the 3rd period is running time (even if the gap shrinks below 7)
- **Timeouts**: One 30-second timeout per game (regulation or overtime)
- **Jerseys**: Coin toss determines home/away; visiting team wears white, home wears dark
- **Roster**: Max 20 players (18 + 1 or 2 goaltenders); minimum 10 players + 1 goaltender to start
- **Bench Staff**: Max 5 accredited people behind the bench
- **Warm-up**: 3 minutes

## Tiebreaker Rules (Article 9.7 - Hockey Quebec)

When teams are tied in points, the following criteria apply **in order**:

| Step | Tiebreaker | What It Means |
|------|------------|---------------|
| a | Highest number of points | Total points accumulated |
| b | Highest number of wins | Team with more wins ranks higher |
| c | Least goals against | Better defense wins |
| d | Most goals for | Better offense wins |
| e | Quickest goal scored | Team that scored the quickest goal in all games played |
| f | Most Franc Jeu points | Fair play bonus points |
| g | By a draw | Random draw |

**Note**: If a team does not show up for a game, all games played against that team by other teams shall not be considered.

## Overtime Rules (Article 9.6.1 - Hockey Quebec)

### Pool Games
- If the score is tied after 3 periods, the game ends in a tie (1 point each)

### Elimination Games (1/8 round, Quarter-Finals)
- 5-minute overtime, stop time, 3v3
- First goal wins
- If still tied, proceed to shootout

### Semi-Finals & Finals
- 10-minute overtime, stop time, 3v3
- First goal wins
- If still tied, proceed to shootout

### Penalty During Overtime
- In the event of a penalty or loss of Franc Jeu point, add one player to the penalized team's opponent

---

## Shootout Rules (Article 9.6.2 - Hockey Quebec)

1. Home team chooses to shoot 1st or 2nd
2. Each team designates 3 shooters for Round 1
3. If still tied after Round 1, coaches designate shooters one at a time
4. All players (except goaltender) must shoot before any player can go again
5. Players serving penalties at end of overtime may still participate
6. Penalty shot rules apply
